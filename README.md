# ТендерФит

Сервис для подрядчиков, которые участвуют в госзакупках: находит закупки под компанию, читает документацию и говорит, стоит ли участвовать и почему, а для строительных лотов считает смету и экономику участия.

Работает на [tender-fit.ru](https://tender-fit.ru). Сервис носит информационно-аналитический характер: оценка отражает соответствие закупки профилю компании и не гарантирует допуск или победу.

## Что умеет

**Поиск закупок**
- Площадки: ЕИС (44-ФЗ, 223-ФЗ, ПП РФ 615), Сбербанк-АСТ, Росэлторг, Фабрикант, ТЭК-Торг, ЭТП ГПБ; Контур.Закупки — платный источник по ключу.
- Кнопка «Найти новые закупки» ищет по профилю человека: его слова, регионы и коды ОКПД2. В ЕИС классификатор передаётся номерами справочника (`okpd2Ids`), как в форме поиска самого сайта.
- Обход региона целиком с отбором по смыслу моделью: находится то, что заказчик назвал другими словами.
- Лента соблюдает выбранный регион, прячет «не подряд» (покупку квартир, мониторинг цен) и показывает, что нового с прошлого визита.
- Закупку можно добавить по ссылке или номеру из ЕИС.

**Анализ**
- Оценка соответствия профилю от 0 до 100 и вердикт «подходит / проверить / не подходит» с причинами.
- Глубокий анализ документации: требования к участнику, риски договора, деньги и сроки, вопросы заказчику. Каждый вывод — с цитатой из документа.
- Сверка с профилем компании и её документами: из загруженных файлов извлекаются только деловые факты (СРО, лицензии, опыт, штат, техника), персональные данные вычищаются до отправки модели.
- Отчёт в Word.

**Смета**
- Локальный сметный расчёт по форме 421/пр из ведомости объёмов, ТЗ или проекта: нормы ФСНБ-2022, цены ресурсов ФГИС ЦС по ценовой зоне региона.
- Проверка сметы заказчика, включая сметы ТСН-2001 (Москва) и Smeta.RU.
- Экономика участия: безубыточная цена, маржа, порог антидемпинга, книга Excel.
- Список «Мои расчёты» по каждому пользователю, письмо со ссылкой на готовый расчёт.

**Работа с закупками**
- «Сегодня»: что горит, что в работе, подача по дням, лучшее из нового.
- «Мои закупки»: доска статусов.
- Ежедневная сводка и письма о готовых разборах.

**Доступ и оплата**
- Вход по почте и паролю, пробный период 7 дней.
- Пакеты «Старт», «Расчёт», «Премиум» (`src/domain/plans.ts`).
- Оплата по счёту для юрлиц и по QR-коду СБП через банк Точка; подписка включается сама после поступления оплаты.

## Как устроено

```
браузер ──► Next.js (приложение, API) ──► PostgREST ──► PostgreSQL (Beget, РФ)
                                    ▲
             воркер на российском сервере: обход площадок, документация,
             глубокий анализ, расчёт смет, почта, сверка оплат
```

- **Приложение** — Next.js 14, React 18, TypeScript (strict), Tailwind.
- **Воркер** — `scripts/worker.ts`: очередь заданий в таблице `sync_jobs` с отдельными дорожками для обхода, живого поиска, документации и смет. Ходит на площадки с российского адреса; запросы к ЕИС проходят через общий затвор с паузой при блокировке (`src/lib/eisGate.ts`).
- **Модель** — Claude Haiku через российский шлюз; каждый вызов пишется в `llm_usage_log` с ценой в рублях.
- **Домен** — чистые функции без сети и хранилища: скоринг, природа закупки, правила поиска, смета (`src/domain/`).
- **Данные** — PostgreSQL 16 с миграциями в `supabase/migrations/`; доступ через PostgREST с API в стиле Supabase.

```
src/
  domain/        правила: скоринг, поиск, смета, оплата, факты компании
  adapters/      площадки (ЕИС, Сбербанк-АСТ, Росэлторг, …), разбор документов
  services/      композиция: анализ, расчёт, почта, банк
  repositories/  база и хранилище браузера
  components/    интерфейс
  app/           страницы и API (App Router)
scripts/         воркер, обход площадок, бенчмарк смет, служебные скрипты
supabase/        миграции базы
deploy/          выкатка на сервер, systemd, nginx, шаблоны окружения
docs/            спецификация, архитектура, справочники по площадкам
```

## Локальный запуск

```bash
npm install
npm run dev
```

Приложению нужна база: `SUPABASE_URL` (адрес PostgREST) и `SUPABASE_SERVICE_ROLE_KEY`. Шаблоны переменных — `deploy/app.env.example` и `deploy/worker.env.example`. В режиме разработки `AUTH_DISABLED=1` отключает вход.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер |
| `npm run typecheck` | проверка типов |
| `npm test` | тесты (Vitest) |
| `npm run lint` | ESLint |
| `npm run build` | прод-сборка |
| `npx tsx scripts/worker.ts` | воркер |
| `npx tsx scripts/estimate-benchmark.ts --tender <номер>` | точность сметы против сметы заказчика |

## Выкатка

Только из ветки `main`: `deploy/stage-from-main.sh` собирает копию, проверяет типы и тесты, `deploy/deploy-app.sh [--with-worker]` выкатывает приложение и воркер. Подробности — в `deploy/README.md`.

Секреты в репозиторий не попадают: значения переменных живут только на сервере.
