# Handoff-спецификация: ТендерФит (tender-fit.ru)

Источник спецификации — рабочий код (`src/app/globals.css`, `tailwind.config.ts`,
`src/components/ui/primitives.tsx`) и проверка живого сайта <https://tender-fit.ru>
в браузере на ширинах 375 / 1280 / 1600 px. Figma-макета у проекта нет, поэтому
токены здесь не «перерисованы с макета», а выписаны из единственного источника
правды — CSS-переменных. Все числа ниже измерены, а не оценены на глаз.

Стек: Next.js 14 (App Router) · React 18 · Tailwind 3.4 · lucide-react · светлая тема (`color-scheme: light`, тёмной темы нет).

> **Состояние на 26.09.2026.** Палитра только что переведена с холодного indigo
> на тёплый оранжевый (референс — дашборд Orbit CRM), и вместе с ней меняются
> примитивы: кнопка стала пилюлей, у пилюль-статусов появилась граница `*-line`,
> добавлены `Stat`/`StatStrip`/`Toolbar`. Разделы 2 и 3 сверены с кодом после
> этого перехода. Если правите палитру дальше — держите в уме пункт 10.9:
> у графиков отчётов своя копия значений, и она не обновляется сама.

## 1. Обзор

Внутренний B2B-дашборд: подрядчик открывает экран «Сегодня» и решает, какие
закупки смотреть сегодня. Три экранных блока идут в порядке вопросов
пользователя — что открыть, что горит, почему остальное отклонено.

| Маршрут | Экран | Ключевой компонент |
|---|---|---|
| `/dashboard` | Сегодня | `DashboardView` |
| `/tenders` | Лента закупок | `TendersView` + `TenderTable` |
| `/tenders/[id]` | Карточка закупки | `TenderDetailView` |
| `/pipeline` | Мои закупки (канбан) | `PipelineBoard` |
| `/reports/daily` | Отчёты | `DailyReportView` |
| `/settings/*` | Профиль / Что ищем / Уведомления | формы |
| `/admin/jobs` | Журнал заданий (без ссылки в меню) | `WorkerQueuePanel` |

## 2. Токены

Цвет задан **тройкой RGB без функции** — `--accent: 79 70 229`. Это осознанно:
Tailwind собирает их как `rgb(var(--accent) / <alpha-value>)`, поэтому работают
модификаторы прозрачности (`bg-accent/10`). Записывать сюда `#4F46E5` нельзя —
сломается весь набор классов с альфой.

### 2.1 Поверхности и текст

| Токен | Значение | Применение |
|---|---|---|
Ряд тёплый нейтральный, а не холодный серо-синий.

| Токен | Значение | Применение |
|---|---|---|
| `--background` | `#F6F6F4` | Холст приложения (`bg-background`) |
| `--panel` | `#FFFFFF` | Карточки и панели |
| `--panel-raised` | `#F5F4F1` | Шапки таблиц, hover строки, чипы |
| `--sidebar` | `#FAFAF8` | Боковое меню — чуть глуше контента |
| `--border` | `#E9E7E3` | Основные разделители |
| `--border-strong` | `#D6D3CD` | Акцентные разделители, ползунок скроллбара |
| `--foreground` | `#1A1816` | Основной текст, тёплый почти-чёрный |
| `--ink` | `#1C1917` | Тёмная заливка: чекбоксы, панель массового действия, тултипы |
| `--ink-soft` | `#3C3935` | Текст длинных документов (`.legal-prose`), 10.6:1 на белом |
| `--muted-foreground` | `#6C6862` | Вторичный текст, 5.3:1 |
| `--faint` | `#7A756D` | Третичный текст и плейсхолдеры, 4.6:1 |

### 2.2 Акценты

Акцент — тёплый оранжевый. Индиго убран намеренно: сине-фиолетовый — дежурный
цвет любого сгенерированного интерфейса, продукт на нём не отличается от соседнего.

Оранжевый разведён на **три** значения, потому что один и тот же оранжевый не
может одновременно быть ярким пятном и проходить AA. Правило прежнее и теперь
строже: базовый тон — только графика и заливки, `*-fg` — текст.
**Не используйте `--accent` для текста.**

| Токен | Значение | Применение |
|---|---|---|
| `--accent` | `#F2541B` | Графика, маркеры, иконки, логотип |
| `--accent-strong` | `#D14311` | Заливка кнопок под белый текст, 4.6:1 |
| `--accent-hover` | `#B3380D` | Hover залитой кнопки |
| `--accent-fg` | `#C2410C` | Мелкий текст и ссылки на белом, 5.2:1 |
| `--accent-subtle` | `#FFF1EB` | Подложка активных элементов |
| `--accent-line` | `#FED7C4` | Граница по подложке акцента |
| `--olive` / `-fg` / `-subtle` / `-line` | `#067647` / `#04663D` / `#ECFDF3` / `#ABEFC6` | Success — «Подходит» |
| `--mustard` / `-fg` / `-subtle` / `-line` | `#CA8A04` / `#854D0E` / `#FFFAE8` / `#FAE5A5` | Warning — «Проверить» |
| `--brick` / `-fg` / `-subtle` / `-line` | `#D92D20` / `#B42318` / `#FEF3F2` / `#FECDCA` | Danger — «Не подходит», риск, ошибка |

Warning уведён в **золото**, а не в оранжевый: оранжевый занят акцентом, и
предупреждение в том же тоне перестало бы читаться как предупреждение. Вердикт
всегда несёт ещё и иконку — цвет не единственный носитель смысла (WCAG 1.4.1).

Группа `brand-50…900` — слой совместимости со старой разметкой. В новом коде не применять.

### 2.3 Типографика

Шрифты подключены `<link>`-ом на Google Fonts, а не `next/font`, чтобы сборка не
падала без сети; офлайн-фолбэки заданы в `tailwind.config.ts`. Загрузку обоих
семейств проверил на живом сайте — Inter и JetBrains Mono отдаются.

| Роль | Семейство | Где |
|---|---|---|
| `font-sans` / `font-display` | Inter 400/500/600/700 | Весь интерфейс |
| `font-mono` | JetBrains Mono 400/500/600 | Класс `.num` — суммы, даты, ИНН, № закупки |

`.num` = `font-mono tabular-nums tracking-tight`. Правило простое: **всё, что
можно сравнить взглядом по вертикали, — моноширинным.**

| Уровень | Размер / начертание | Где |
|---|---|---|
| H1 экрана | 24 px / 600 / `tracking-tight` (измерено: `letter-spacing: -0.6px`, `line-height: 36px`) | «Здравствуйте, {legalName}» |
| Заголовок карточки | 15 px / 600 / `tracking-tight` | `Card title` |
| Строка списка | 14.5 px / 500 | `TodayRow` |
| Основной текст | 13–14 px / 400 | Мета-строки, описания |
| Подпись | 11–12 px / 400 | Метки, источники, сноски |
| Шапка таблицы | 11 px / 500 / `uppercase` / `tracking-[0.06em]` | `thead th` |

| Токен | Значение | Применение |
|---|---|---|
| `rounded-card` | 16 px | Карточки |
| `rounded-control` | 10 px | Поля, пункты меню, плитки |
| `rounded-pill` / `rounded-full` | 999 px | Кнопки, пилюли-статусы, аватар |

## 3. Компоненты

### 3.1 `Button` (`ui/primitives.tsx`)

База: `inline-flex items-center justify-center gap-2 rounded-full font-medium transition-colors`.
Кнопка-пилюля — главный узнаваемый элемент референса.

| Вариант | Покой | Hover | Назначение |
|---|---|---|---|
| `primary` | `bg-accent-strong` + белый текст + тень | `bg-accent-hover` | Единственный на экране |
| `secondary` | `bg-panel` + `border-border` | `bg-panel-raised`, `border-border-strong` | Действия второго плана |
| `ghost` | прозрачный, `text-muted-foreground` | `bg-panel-raised` | Иконочные и служебные |
| `danger` | `bg-brick` + белый текст | `bg-brick-fg` | Удаление |
| `outline` | прозрачный, `text-accent-fg`, `border-accent-line` | `bg-accent-subtle` | Альтернатива primary |
| `ink` | `bg-ink` + белый текст + тень | `bg-ink/90` | Действия поверх выделения, «сильный» вторичный CTA |

**`primary` залит `--accent-strong`, а не ярким `--accent`**: белый текст на
`#F2541B` даёт 3.1:1 и не проходит AA. Яркий оранжевый остаётся на графике.

| Размер | Метрика |
|---|---|
| `sm` | `px-3.5 py-1.5`, 13 px |
| `md` (по умолчанию) | `px-[18px] py-2.5`, 14 px |
| `lg` | `px-6 py-3`, 15 px |

Focus: `ring-2 ring-accent/35` + `ring-offset-1`. Disabled: `opacity-50 cursor-not-allowed`.

`loading` — ожидание выполнения: слева появляется `Loader2` в размер кнопки
(`sm` 14 px, `md` 16 px, `lg` 20 px), проставляется `aria-busy` и кнопка сама
становится `disabled` — «ждём» и «можно нажать ещё раз» одновременно не бывает.
Спиннер уважает `motion-reduce`. Собственный `disabled` продолжает работать и
складывается с `loading` по «или».

### 3.2 `Card`

`bg-panel` + `border border-border` + `rounded-card` (16 px) + `--card-shadow`.
При наличии `title`/`actions` появляется шапка `px-5 py-4` с нижней границей;
тело — `p-5`, а с пропом `flush` — без отступов (таблицы и списки во всю карточку).

### 3.3 `Badge` и `VerdictBadge`

Мягкая заливка, текст того же тона и **тонкая граница в тон** (`*-line`).
`rounded-full border px-2.5 py-[3px]`, 12 px / 500, `whitespace-nowrap`.
Тона: `olive` · `mustard` · `brick` · `neutral` · `accent`. Точка 6×6 px
(`bg-current opacity-80`) включена по умолчанию, отключается `dot={false}`.

Граница здесь не украшение: без неё светлая пилюля растворяется на белой строке
таблицы и статус приходится искать глазами.

**Короткие подписи вердикта** (`verdictShort`, используются только в таблице):
«Подходит» · «Проверить» · «Не подходит». Полные (`verdictLabels`) — везде, где
есть место: «Можно участвовать» · «Нужно посмотреть» · «Не подходит».
Короткая подпись обязана быть короче полной — иначе колонка обрезает её (см. 7.8).

`VerdictBadge` заменяет точку на иконку 12×12 (`ThumbsUp` / `AlertTriangle` /
`ThumbsDown`): **вердикт не кодируется одним лишь цветом** — иконка и текст несут
то же значение. Пропсы `short` (короткая подпись для таблицы) и `full`.

### 3.4 `FitScore`

Число 0–100, обрезается `clamp(0, 100)`. Тон по порогам: `≥75` olive, `≥50`
mustard, иначе brick. `role="img"` + `aria-label="Fit Score {n} из 100"` —
скринридер не должен читать голое число без шкалы.
Размеры: `sm` 11 px, `md` 13 px, `lg` 16 px.

### 3.5 Прочие примитивы

| Компонент | Контракт |
|---|---|
| `Field` | `label` / `hint` / `error`; при `error` подсказка скрывается, ошибка получает `role="alert"` |
| `Input` / `Textarea` / `Select` | Общий класс `.input`: `rounded-control`, `px-3.5 py-2.5`, focus `ring-2 ring-accent/30` + `border-accent` |
| `ProgressBar` | Высота 6 px, `role="progressbar"` + `aria-valuenow/min/max` |
| `LoadingSkeleton` | `rows` полос 48 px, `animate-pulse`, `aria-busy="true"`, `aria-label="Загрузка"` |
| `EmptyState` | Заголовок + описание, `py-12`, по центру |
| `ErrorState` | `text-brick-fg` + необязательная кнопка «Повторить» |
| `Collapsible` | `aria-expanded`, индикатор `+` / `−` |
| `Stat` / `StatStrip` | Полоса показателей: один контейнер с разделителями, а не N карточек. `delta` печатается тоном результата — «+12%» и «−12%» различаются одним символом и на скорости не читаются |
| `Toolbar` / `SegButton` | Ряд инструментов над таблицей (`.seg`): прозрачные пилюли с границей — набор читается как один инструментальный ряд, а не как пять призывов к действию. Активное состояние через `aria-pressed` / `data-active` |
| `Toggle` | Переключатель |
| `Counter` | Плитка-счётчик: подпись, крупное число, тон при необходимости внимания |

## 4. Состояния и взаимодействия

| Элемент | Состояние | Поведение |
|---|---|---|
| Пункт меню | Активный | `bg-accent-subtle text-accent-fg font-medium`, иконка `text-accent`, `aria-current="page"` |
| Пункт меню | Hover | `bg-panel-raised text-foreground` |
| Активность считается | — | `pathname === href` или `pathname.startsWith(href + "/")` |
| Строка «Откройте сегодня» | Hover | `shadow-card` → `shadow-card-hover` (`transition-shadow`) |
| Строка таблицы | Hover | `bg-panel-raised/50` |
| Заголовок колонки | Активная сортировка | `ArrowUp`/`ArrowDown` в `text-accent`; иначе `ArrowUpDown` в `text-faint` |
| «Не подошло — почему» | Раскрытие | Кнопка с `aria-expanded`, шеврон `rotate-180` |
| «Найти новые закупки» | Нажатие | **Поиск не запускается.** Открывается панель с двумя действиями: прогон бесплатных площадок (ставит задание в очередь сервера в России) и платный поиск агрегатора. Цена платного поиска показывается до списания, а не после |
| Сбой синхронизации | Ошибка | Карточка с `AlertTriangle` и текстом ошибки от источника; совет «проверьте интернет» намеренно не даётся — причина обычно в 429/401/503 источника |

### Экран «Сегодня» — правила наполнения

| Константа | Значение | Смысл |
|---|---|---|
| `TOP_TODAY` | 3 | Строк в «Откройте сегодня» |
| `URGENT_SHOWN` | 5 | Строк в «Срочно» |
| `REJECTED_SHOWN` | 5 | Причин в раскрытом «Не подошло» |
| `URGENT_DEADLINE_DAYS` | из `domain/scoring` | Порог блока «Срочно» |

- Просроченные закупки не попадают ни в «Откройте сегодня», ни в «Срочно».
- Закупки последнего прогона исключаются из «Откройте сегодня» — иначе один и тот же список занимает место дважды.
- Если всё подходящее ушло в блок последнего поиска, показывается «Всё подходящее — в последнем поиске выше», а **не** «подходящих закупок нет»: второе было бы ложью.
- Блок «Результат последнего поиска» не рисуется пустым — пустой блок утверждал бы, что поиск был.

## 5. Адаптив

Брейкпоинты — стандартные Tailwind. Фактически используются `sm` (640) и `lg` (1024); `md` встречается дважды.

| Ширина | Поведение |
|---|---|
| `< 1024` | Сайдбар `display: none`, открывается бургером как выдвижная панель (`fixed inset-y-0`, `z-40`) поверх затемнения `bg-black/40` (`z-30`). Padding `main` 16 px |
| `≥ 1024` | Сайдбар `sticky`, 248 px, всегда виден. Padding `main` 28 px |
| `≥ ~1490` | Только начиная отсюда таблица закупок помещается целиком (с колонкой «Приоритет» — с ~1600); ниже она прокручивается по горизонтали внутри своей карточки — см. 7.1 |

Шапка `sticky top-0 z-20`, `bg-panel/90` + `backdrop-blur-sm`, тень-линия вместо границы.

`main` использует `overflow-x-clip`, а **не** `overflow-x-hidden`: `hidden`
превращает `main` в scroll container и ломает `position: sticky` у якорной
навигации в карточке закупки. Не меняйте это на `hidden`.

Горизонтального переполнения страницы на 375 px нет (проверено: `scrollWidth === clientWidth === 375`).

## 6. Граничные случаи

| Случай | Поведение |
|---|---|
| Нет данных вообще | `EmptyState` «Закупок пока нет» + кнопка «Указать, что ищем», если профилей поиска нет |
| Нет подходящих | `SearchEmptyExplanation` — разбор, чем отсеялись, + «Найти новые закупки» и «Изменить условия поиска» |
| Нет отклонённых | «Отклонённых закупок нет» |
| Нет горящих сроков | Явная фраза «в ближайшие N дней подача не закрывается», а не пустота |
| Загрузка | H1 остаётся, под ним «Загрузка…», тело — `LoadingSkeleton rows={6}` |
| Ошибка загрузки | Экран целиком заменяется `ErrorState` с «Повторить» |
| Заказчик/регион неизвестны | Заглушка **не печатается**: две заглушки подряд читаются как поломка. Цена печатается всегда — её отсутствие само по себе факт |
| Цена не опубликована | Текст 11 px `text-muted-foreground` (не `.num`) + подсказка про запросы цен |
| Валюта не рубль | Печатается валюта закупки; «₽» рядом с долларовой суммой — дезинформация |
| Длинный предмет закупки | `line-clamp-1` в списке, `line-clamp-2` в таблице, полный текст в `title` |
| Длинное имя заказчика | `line-clamp-1` + `title`. Реальные названия — «МКУ „Управление по Обеспечению Деятельности…“» — на 160 px колонке обрезаются почти всегда |
| Склонения | Только через `pluralRu(n, [...])`. Не собирайте строки вручную |
| Колонка «Главный риск» | Скрывается целиком, если риска нет ни у одной строки |
| Колонка «Приоритет» | Появляется только при активном поиске и ненулевой релевантности |

## 7. Дефекты, найденные при подготовке хендоффа

Найдены при сверке кода с живым сайтом. Все, кроме 7.3, исправлены — ниже
сохранены и симптом, и причина: это те грабли, на которые наступают повторно.
Проверка после правок: `tsc` и `eslint` чистые на изменённых файлах, 1500 тестов
в 78 файлах проходят, поведение снято на дев-сервере.

### 7.1 ✅ Исправлено — таблица закупок обрезалась без возможности прокрутки (блокер)

`TenderTable` — `table-fixed` с жёсткими ширинами колонок, сумма **1134 px**
(112+116+240+104+160+92+92+126+92). Обёртка — `card overflow-hidden !p-0`, то
есть `overflow-x: hidden`. Прокрутки нет, обрезанное недостижимо.

Измерено:

| Вьюпорт | Ширина обёртки | Ширина таблицы | Срезано |
|---|---|---|---|
| 375 px | 341 px | 1134 px | **793 px** (6 колонок из 9 целиком) |
| 1280 px | 964 px | 1134 px | **170 px** (колонка «Статус» и часть «Главного риска») |
| 1600 px | 1284 px | 1284 px | 0 |

Комментарий в коде утверждает «суммарно ~1084px — помещается в 1440px». Сумма на
самом деле 1134, и при `main` = ширина − 304 px таблица начинает помещаться
только с ~1438 px. При активном поиске добавляется «Приоритет» (+104 px) — нужно
уже ~1542 px, то есть на 1440 px экране колонка срезается даже в лучшем случае.

Минимальное исправление — заменить на обёртке `overflow-hidden` на
`overflow-x-auto` (радиус карточки сохранится). Правильное — приоритизация
колонок: ниже `lg` оставить «Вердикт · Fit · Предмет · Подача до», остальное
свернуть в раскрывающуюся строку. Сейчас мобильный пользователь ленты не видит
ни срока подачи, ни цены.

**Сделано.** Обёртка получила `overflow-x-auto` вместо `overflow-hidden` (радиус
карточки сохраняется — `overflow` всё ещё не `visible`), плюс `tabIndex={0}`,
`role="region"` и `aria-label="Таблица закупок"`: по WCAG 2.1.1 до прокручиваемой
области нужно добираться и с клавиатуры, а не только колесом. Комментарий в файле
приведён к фактическим числам.

Проверено после правки (на живом дев-сервере, вместе с 7.8): на 1280 px
прокрутка доходит до правого края — 212 из 212, на 375 px — 817 из 817,
горизонтального переполнения страницы нет. На 1492 px прокрутки уже нет:
обёртка 1168 px, таблица 1158 px.

Осталось решением дизайна: приоритизация колонок вместо прокрутки. Доступ к
данным прокрутка вернула, но читать девять колонок с телефона всё равно неудобно.

### 7.2 ✅ Исправлено — `text-destructive`, несуществующий токен

`src/components/dashboard/DashboardView.tsx` — иконка ошибки синхронизации была
помечена `text-destructive`. В `tailwind.config.ts` токена `destructive` нет
(это имя из shadcn/ui, проект использует `brick`). Класс не компилировался, иконка
наследовала цвет текста и теряла сигнальную роль ровно в том месте, где она нужна.

**Сделано.** Заменено на `text-brick` — базовый тон, а не `*-fg`: это иконка
20×20, а не мелкий текст.

### 7.3 ⏳ В работе отдельно — мобильное меню не выполняет контракт модального слоя

Проверено на живом сайте при открытой панели:

| Ожидается | Фактически |
|---|---|
| Фокус переходит в панель | Остаётся на кнопке «Открыть меню» |
| `Escape` закрывает | Не закрывает, панель остаётся `display: flex` |
| Фон не прокручивается | `body { overflow: visible }` — фон скроллится под панелью |
| `role="dialog"` + `aria-modal="true"` | Атрибутов нет |
| Возврат фокуса на бургер при закрытии | Не реализован |

Клик по затемнению работает, но у затемнения `aria-hidden` и нет доступной
альтернативы с клавиатуры. Клавиатурный пользователь на мобильной ширине
открывает меню и не может его закрыть.

### 7.4 ✅ Исправлено — фон `html` и `body` не совпадали

`src/app/layout.tsx` задавал `html` инлайновый `backgroundColor: "#F7F8FA"`, а
`globals.css` — `--background: #F5F6FA`. Измерено на живом сайте: `html` =
`rgb(247,248,250)`, `body` = `rgb(245,246,250)`. Разница была видна при
overscroll-подтяжке.

**Сделано.** Инлайновый стиль снят: `globals.css` и так красит `html` и `body`
из `rgb(var(--background))`. После правки оба = `rgb(245,246,250)`.

### 7.5 ✅ Исправлено — цвета мимо палитры и отсутствующий `loading`

- `Checkbox` использовал хардкод `accent-[#55657E]` — цвет вне палитры. Заменён на `accent-[rgb(var(--accent))]`.
- У `Button` не было состояния `loading`, хотя ожидание показывают минимум два экрана (поиск, синхронизация), и каждый рисовал его вручную. Добавлен проп `loading` — см. 3.1.
- `LoadingSkeleton` пульсировал и при `prefers-reduced-motion: reduce`. Добавлен `motion-reduce:animate-none`.

### 7.6 ✅ Исправлено — графики отчётов жили на своей палитре

Найдено при правке 7.5: `ReportCharts.tsx` содержал **13 хардкод-цветов**, из
которых часть пережила смену палитры. Вердикты рисовались защитно-оливковым
`#607A4F`, коричневым `#9A6B38` и кирпичным `#A34C42` — то есть «Подходит» на
графике был одного цвета, а на пилюле `VerdictBadge` рядом совсем другого
(`#16A34A`). Сетка, подписи и тултип тоже шли мимо токенов (`#E4E7EC` вместо
`#E7E9F0`, `#1F2933` вместо `#15161C`, `#F2F4F7` вместо `#F3F4F9`).

**Сделано.** Введена таблица `chartColors` — зеркало токенов. Значения остались
литералами намеренно: Recharts отдаёт цвет в презентационный атрибут SVG
(`fill`/`stroke`), а `var()` в атрибутах не раскрывается — работает только в
CSS-свойствах. Отсюда правило: **меняется токен — правится и `chartColors`**,
другого способа держать графики в одной палитре с интерфейсом нет.

Проверено после правки: в SVG остались только `#4F46E5`, `#15161C`, `#667085`,
сегменты вердиктов — `rgb(22,163,74)` / `rgb(217,119,6)` / `rgb(220,38,38)`.

### 7.8 ✅ Исправлено — ширины колонок таблицы были подобраны на глаз

Замер фактического контента на живой странице показал три расхождения сразу:

| Колонка | Было | Нужно контенту | Симптом |
|---|---|---|---|
| Вердикт | 112 px | 135 px | Обрезался **каждый** вердикт: «Нужно посмотреть» → «Нужно посм» |
| Fit | 116 px | 55 px | **85 px мёртвой ширины** под шкалу-трек, которую `FitScore` давно не рисует |
| НМЦК | 92 px | 140 px | Цена вылезала в соседнюю ячейку в 5 строках из 6 |

Корневая причина обрезки вердикта — не ширина, а подпись: `verdictShort`
для `MANUAL_REVIEW` дословно повторял `verdictLabels` («Нужно посмотреть»), то
есть короткий вариант не был коротким. А это самый частый вердикт в выдаче.

**Сделано.** `verdictShort.MANUAL_REVIEW` → «Проверить» (полная формулировка
осталась везде, где есть место). Ширины пересобраны по замеру: Вердикт 136,
Fit 64, НМЦК 148, Подача до 104, Закон 88, Приоритет 112. Сумма 1158 px против
1134 — на 24 px больше, но теперь ничего не обрезается и не наезжает.
«Главный риск» оставлен 126 px: замерить его отдельно не удалось, а сужать на
глаз — это ровно та ошибка, которую здесь чинят.

Добавлена утилита `.scroll-hint-x`: тень у края области появляется только когда
за краем действительно есть содержимое (чистый CSS на `background-attachment:
local`, без JS). Прокручиваемая таблица без такого признака выглядит просто
обрезанной — пользователь не знает, что справа есть ещё колонки.

**Проверено на живом дев-сервере после смены палитры:** обрезанных вердиктов 0
(было — в каждой строке), переполнений цены 0 (было 5 из 6), подписи в колонке —
«Проверить» и «Не подходит», фактические ширины ровно 136 / 64 / 240 / 88 / 160 /
148 / 104 / 126 / 92 = 1158 px, четыре слоя градиента `.scroll-hint-x` на месте.

## 8. Анимация

| Элемент | Триггер | Анимация | Длительность | Easing |
|---|---|---|---|---|
| Строка таблицы | Появление | `row-in`: `opacity 0→1`, `translateY(4px)→0` | 260 ms | `cubic-bezier(.22,.61,.36,1)` |
| Строка таблицы | Каскад | `animation-delay: min(i, 14) × 50ms` — задержка ограничена 700 ms, иначе хвост длинной страницы доезжал бы секундами | — | — |
| Карточка закупки | Hover | Смена тени | по умолчанию | по умолчанию |
| Кнопка, пункт меню | Hover | `transition-colors` | по умолчанию | по умолчанию |
| Полоса прогресса | Смена значения | `transition-all` по `width` | по умолчанию | по умолчанию |
| Скелет | Загрузка | `animate-pulse` | — | — |

`prefers-reduced-motion: reduce` отключает `row-in` (media-блок в `globals.css`),
а `LoadingSkeleton` и спиннер `Button` — через утилиту `motion-reduce:animate-none`.
**Любая новая анимация обязана попасть в один из этих двух механизмов.**

## 9. Доступность

Что уже сделано:

- `lang="ru"` на `<html>`.
- Вердикт передаётся цветом **и** иконкой **и** текстом.
- Текстовые токены подобраны под контраст AA (≥ 4.5:1) на всех трёх поверхностях; для мелкого текста используется пара `*-fg`.
- `aria-current="page"` на активном пункте меню; `<nav aria-label="Хлебные крошки">`.
- Видимый focus-ring на кнопках (`ring-accent/40`) и полях (`ring-accent/30`).
- `role="progressbar"`, `role="alert"` на ошибке поля, `aria-busy` на скелете, `aria-expanded` на всех раскрывашках.
- Декоративные иконки помечены `aria-hidden`.
- Закрытый сайдбар на мобильной ширине — `display: none`, то есть не попадает в порядок обхода табом.

Что нужно доделать:

1. Мобильное меню: `role="dialog"` + `aria-modal="true"`, фокус-ловушка, `Escape`, блокировка прокрутки фона, возврат фокуса на бургер (7.3 — делается отдельно).
2. Ссылка «Пропустить к содержимому» перед сайдбаром — сейчас клавиатурный пользователь проходит 8 пунктов меню на каждой странице.
3. Порядок обхода: сайдбар → шапка → `main`. Соответствует DOM; единственный намеренный `tabIndex={0}` — на прокручиваемой обёртке таблицы (7.1), это требование WCAG 2.1.1, а не украшение.

## 10. Правила для новых экранов

1. **Цвет только через токен.** Хардкод hex в разметке — ошибка (см. 7.5).
2. **Мелкий текст — парой `*-fg`.** Базовый тон на 11–13 px не проходит AA.
3. **Числа — `.num`.** Суммы, даты, ИНН, номера закупок.
4. **Не изобретайте примитив.** Кнопка, карточка, пилюля, поле, скелет, пустое состояние уже есть в `ui/primitives.tsx`.
5. **Заглушка вместо данных — только если отсутствие данных само является фактом.** Иначе элемент не печатается.
6. **Склонения — через `pluralRu`.**
7. **Каждая новая анимация — в блок `prefers-reduced-motion`.**
8. **Фиксированная ширина в таблице — только вместе с `overflow-x-auto`.** И прокручиваемая область получает `tabIndex={0}` + `role="region"` + `aria-label`.
9. **Меняете токен цвета — правьте и `chartColors` в `ReportCharts.tsx`.** Графики не могут читать CSS-переменные (см. 7.6), это единственное место с легальным дублированием палитры.
