# Референсы-конкуренты: Контур.Закупки, «Открытые торги», «ТендерГруппа»

> Осмотр 21.09.2026, дополнено 01.10.2026. Дополняет [REFERENCE_PUBLIC_CATALOG.md](./REFERENCE_PUBLIC_CATALOG.md):
> там — устройство публичной витрины, здесь — позиционирование, лендинг и страница доверия.

## 1. Контур.Закупки (zakupki.kontur.ru/site) — продуктовый SaaS

Платный сервис поиска и аналитики (440+ площадок). Лендинг, а не открытая витрина: выдача закрыта за регистрацией.

Что на лендинге и что из этого полезно нам:

- **Поиск-вход прямо на лендинге**: одно поле «Ключевое слово, номер закупки, город или код ОКДП» + кнопка «Найти». Рядом быстрые пресеты-ссылки: «Закупки по 44-ФЗ», «по 223-ФЗ», «Коммерческие закупки», «Малые закупки» (deep-link на сохранённые поиски). Рядом же вторичная ссылка «проверьте заказчика на надёжность» → отдельный продукт Analysis.
  → Берём: пресеты-quicklinks на нашей витрине + единое поле поиска, понимающее несколько типов запроса.
- **Возможности поданы как жизненный цикл** вкладками: Оценка спроса → Поиск закупок → Анализ тендера → Проверка заказчика → Планирование участия → Уведомления о важном.
  → Берём: нашу страницу «Возможности» строить по стадиям жизненного цикла, а не списком фич; это совпадает с нашим пайплайном (воронка, отчёты, уведомления).
- **Открытые тарифы с якорем**: Стандарт 23 600 ₽/год, Эксперт 46 400 ₽/год («максимум критериев + аналитика с помощью ИИ»), зачёркнутая «старая цена», покупка онлайн без менеджера, бесплатный пробный период 3 дня со всеми возможностями.
  → Берём: открытые цены + якорная «старая цена» + онлайн-оплата + ограниченный бесплатный триал вместо «навсегда бесплатной» витрины.
- **FAQ-аккордеон под возражения**: сколько стоит найти закупку, что доступно бесплатно, по каким параметрам поиск, как часто обновляются данные, как оценить шансы на победу, можно ли работать в команде, откуда данные.
  → Берём: тот же набор возражений закрыть на нашем лендинге (особенно «как часто обновление» и «как оцениваются шансы» — у нас на это есть честный ответ про детерминированный скоринг).
- **Сигналы доверия**: ПО в реестре российских программ, поддержка 24/7, интеграция в CRM через API, Журнал (блог) + телеграм-канал.
- **SEO-футер хабы**: 44-ФЗ, заказчики, регионы, малые закупки, отрасли + законодательство и список ЭТП.

Чего НЕ берём: закрытую выдачу (у нас витрина открыта — это наше отличие и SEO-актив) и платный доступ к базовому поиску.

## 2. «Открытые торги» (zakupki1.ru/o-kompanii) — агентство сопровождения

Не продукт, а услуги: тендерное сопровождение, обучение, консультации. Страница «О компании» — эталон страницы доверия для B2B-услуг.

Схема страницы доверия:

- Короткое позиционирование: «единая точка входа», полный комплекс, работаем и с новичками, и с развитыми тендерными отделами.
- Блок «Наша задача / Наша цель» — две карточки с миссией.
- **Проверяемые факты**: «8 лет в сопровождении» со ссылкой на whois даты регистрации домена; «более 1200 компаний с 2013 года»; «услуги от 1 часа».
- **Карусель логотипов клиентов** + **карусель отзывов** с ссылками на реальные сайты клиентов (Samsung, Unilever, Zeppelin и др.).
- **Принципы** списком с жирным лид-словом: управляем рисками, экономим время, работаем для пользы, уменьшаем согласования, храним секреты (NDA), выдерживаем сроки.
- Реквизиты и контакты; в шапке постоянные CTA «Отправить заявку» / «Заказать звонок» + телефон.

→ Берём для нашей страницы «О компании»/доверия: проверяемые факты вместо прилагательных, принципы с лид-словами (включая конфиденциальность/NDA — важно для B2B), реквизиты, телефон + обратный звонок в шапке. Карусели отзывов/логотипов — только когда появятся реальные клиенты и реальные отзывы (сейчас у нас демо-режим, фейковые логотипы запрещены стандартами проекта).

→ Идею услуги: «сопровождение/обучение» как апселл поверх продукта — запись в ROADMAP, не в MVP.

## 3. «ТендерГруппа» (tendergruppa.ru) — дешёвые сигналы поверх зеркала ЕИС

> Осмотр 01.10.2026: лендинг и публичные страницы напрямую, экран `/app/nocomp` — по
> скриншоту рабочего кабинета (выдача закрыта логином: email + пароль, без входа только форма).

- Позиционирование без обмана: «агрегатор госзакупок 44-ФЗ и 223-ФЗ из открытых данных ЕИС»,
  «забираем официальные выгрузки, разбираем их и обновляем базу несколько раз в час».
  В базе 108 259 активных закупок из 89 регионов, с историей около 6 900 000.
  Ни слова про 400 площадок: источник один — ЕИС. Чипы «РТС-тендер» и «АО „Сбербанк-АСТ“»
  в строках выдачи — поле «площадка размещения» извещения ЕИС, а не отдельные источники.
- `/app/nocomp` («Закупки, где нет конкурентов») — сохранённое представление: отбор по числу
  заявок в завершённых процедурах (0–1 заявка, бейдж «Без конкуренции»). На скриншоте все
  строки «Завершена»: это постфактум-отчёт о прошлых торгах, а не вердикт по активным.
  Прогноз «низкая конкуренция через 48 ч» — их надстройка над теми же данными ЕИС.
- Цены: 1 500 ₽/месяц, 8 000 ₽/полгода, 14 000 ₽/год, триал 3 дня без карты. Годовой тариф
  в 1,7 раза дешевле контуровского «Стандарта» (23 600 ₽/год): продаёт сигнал, а не покрытие.
- Поиск: несколько ключевых фраз сразу, фильтры по географии, цене, ОКПД2, закону, СМП;
  Telegram-бот каждые 5 минут плюс ежедневная почтовая сводка.

Что берём:

- Signal-views как пункты левого меню: «Горящие», «Ноль заявок», «Победители». У нас уже есть
  слои свежести и «Закрывается < 24 ч»; недостающий вид — «Без конкуренции» по истории ЕИС:
  процедуры того же заказчика и ОКПД2 завершались одной заявкой. Считается из наших данных,
  внешнего источника не требует. В MVP не входит — запись в ROADMAP.
- Типографию строки: предмет в две строки крупным кеглем плюс строка чипов под ним.
  Реализовано 01.10.2026 в `TenderTable`: колонка «Закон» (88px) уехала чипами в ячейку
  предмета, предмет 328px и 16px вместо 240px и 15px, суммарная ширина таблицы не изменилась.
- Дедлайн второй строкой факта («приём заявок завершён») — у нас пока только «< 24 ч».

Чего НЕ берём: постфактум-сигнал как главный продукт (наше значение — вердикт по активной
закупке до подачи заявки) и платный вход в ленту без аналитики поверх неё.
