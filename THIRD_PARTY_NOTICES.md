# Уведомления о сторонних компонентах

Файл обязателен к распространению вместе с продуктом. Здесь перечислены
компоненты, лицензии которых требуют сохранения уведомлений.

## node-unrar-js

Чтение архивов RAR. Обёртка на JavaScript/WebAssembly вокруг исходного кода
UnRAR от RARLAB.

- Пакет: MIT.
- Внутри: исходный код UnRAR, лицензия RARLAB.

Лицензия UnRAR разрешает безвозмездно использовать исходный код для обработки
архивов RAR, но запрещает:

- использовать исходный код для создания архиватора, совместимого с RAR;
- восстанавливать по нему проприетарный алгоритм сжатия RAR.

Проект использует компонент только для **чтения и извлечения** содержимого
архивов, упаковщик RAR не создаёт и алгоритм сжатия не восстанавливает — этот
сценарий лицензией прямо разрешён.

Полный текст: `node_modules/node-unrar-js/LICENSE` и файл лицензии UnRAR в
составе пакета.

## 7z-wasm

Чтение архивов 7z. Сборка 7-Zip в WebAssembly.

- Файлы `7zz.*.js` и `7zz.wasm`: LGPL с ограничением unRAR.
- Остальные файлы пакета: LGPL.

Уведомления о лицензиях нельзя удалять при сборке.

Полные тексты: `node_modules/7z-wasm/License.txt` и
`node_modules/7z-wasm/unRarLicense.txt`.

## Шрифт Inter

Файлы `src/assets/fonts/Inter-Bold.ttf` и `Inter-Medium.ttf` — шрифт Inter
(Rasmus Andersson). Им набран текст картинки превью ссылки на сайт
(`src/app/opengraph-image.tsx`).

- Лицензия: SIL Open Font License 1.1 — разрешает встраивать и распространять
  шрифт вместе с продуктом; продавать сам шрифт отдельно нельзя.
- Текст лицензии: https://openfontlicense.org

## Что это значит на практике

- Удалять license notices из сборки нельзя.
- Этот файл должен уезжать вместе с продуктом; если появится экран «Лицензии» в
  интерфейсе, его содержимое берётся отсюда.
- Ограничение UnRAR не мешает текущей задаче: проект распаковывает документацию
  закупок, а не пакует архивы.
